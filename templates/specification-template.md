# Specification Template

**Version:** 1.2
**Date:** 2026-04-29
**Status:** Reusable template

**When to use this:** Use once the idea is stable enough to formalize systems, constraints, and intended behavior.

**Layout:** A spec can be a single file (`docs/specification.md`) or a directory (`docs/specs/` with one file per concern plus `docs/specs/index.md`). Start single-file. Split only when a section grows large enough that its own audience or depth justifies it. The same sections apply either way.
